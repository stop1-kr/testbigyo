# 돈 모아 결혼하기 프로젝트 (중3 · 5차시)

GitHub Pages로 배포해 아이패드에서 사용하는 정적 웹앱입니다.

## 배포
1. GitHub 저장소를 만들고 이 폴더의 파일을 **루트에 그대로** 올립니다.
2. Settings → Pages → Source: `Deploy from a branch` → `main` / `(root)` 저장.
3. `https://<아이디>.github.io/<저장소명>/` 으로 접속합니다. (모든 경로가 상대경로라 저장소 이름과 무관하게 동작합니다.)
4. 아이패드 사파리에서 공유 → **홈 화면에 추가** 하면 앱처럼 쓸 수 있습니다.

## 파일
- `index.html` : 홈(이름 입력, 5차시 링크, 진행률, 기록 백업/복원)
- `lesson1.html` : 1차시 완성본
- `lesson2~5.html` : 준비 중 페이지
- `css/style.css`, `js/store.js`(자동 저장), `js/jobs-data.js`·`data/jobs.json`(직업 참고 데이터)

## 이번 수정(요청 반영)
1. 직업을 바꾸면 관련 학과·평균 연봉·직업 만족도가 **채워져 있어도 즉시 새로 반영**됩니다. (`참고 정보 다시 불러오기` 버튼도 추가)
2. `고용24에서 찾기` 링크 삭제.
3. 성별·지역을 고르면 ①취직 나이·⑥희망 결혼 나이·⑦결혼 비용이 **채워져 있어도 다시 채워집니다.**
4. 161만원 참고 문구에 "(특이값이 있기 때문에 중앙값을 추측해서 계산해보기)" 추가.
5. 20~24세(210만원)·25~29세(250만원) 중위연봉을 ②번(취직 전 저축)의 참고로 이동. ③번에는 30~34세 290만원과 `1단계 연봉으로 계산하기`만 남김.
6. "아르바이트 2030년 예상 최저시급 12,000원" 참고 추가.
7. ②번에 계산 예시 문장 + 접이식 계산 도우미(주당 시간·시급·기간·군대 저축·소비 입력) 추가.
8. ③번 `1단계 연봉으로 계산하기` 버튼을 맨 앞에 두고 진한 남색(primary) 버튼으로 변경.
9. ④번 버튼 아래에 `(③ 월급) × (저축률) = 결과` 계산식이 실시간 표시.
10. ⑦번 '내가 준비할 비율' 기본값 50%.

## 주의
- 학생 입력은 **해당 기기·브라우저(localStorage)** 에만 저장됩니다. 차시 끝에 홈에서 JSON 백업 또는 결과 요약 복사/PDF 저장을 루틴으로 하세요.
- `js/jobs-data.js`의 연봉·만족도는 **근사 예시값**입니다. 수업 전 커리어넷 등에서 확인한 값으로 수정해 주세요.
- 커리어넷 오픈API는 인증키·CORS 문제로 GitHub Pages에서 직접 호출이 어렵습니다. 3차시 주식·금·부동산 자료도 **연도별 JSON을 저장소에 미리 넣는 방식**을 권합니다.
